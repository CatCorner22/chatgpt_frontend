# Handoff stages 4–6

Assumptions: preserve existing behavior; public-page extraction is partial, never proof that an app works. Outside coding tools cannot be operated here; sample integrations are simulations.

| Slice | Files | Check |
|---|---|---|
| Safe transfer | exportPack, design, pack tests | Every file audited; inert install, scoped opt-in, framework-specific bridges, complete rollback; browser tasks unchanged and exact CSS rollback |
| Design and preservation evidence | pure transfer checks, critic function/page, Rescue | Known mismatches and removed links/forms/fields detected; unknown evidence never passes |
| Clear journey and comparison | home, journey, comparison | Three paths and image comparison on phone/desktop; screenshots stay in browser |
| Security and launch review | review report, security regression tests | Live policies + two disposable users; public links; scans; honest go/no-go |

Launch blockers are recorded, not silently accepted. Publishing, pricing, outside-tool execution, real user studies and legal approval remain outside this implementation.
