# Can people use the design we delivered?

Focus’s layout browser can show the same words in six arrangements. Its release test follows each selection through Studio and compares the actual HTML and ZIP with the preview. The River Kiln study kit already records booking outcomes and a separate preference ballot. The next question is whether people understand what they see, especially when a detail changes. The three experiments below are proposals. No participant results were collected for this review. [Layout release test](../scripts/test-layout-browser.mjs) · [River Kiln study protocol](RIVER-KILN-DESIGNER-STUDY.md)

## 1. Can a visitor tell what they will pay?

The offline pilot includes two standalone Focus pages, a moderator guide and a blank tally. Extract the ZIP, open START-HERE.txt and give each visitor only their assigned page. [Download the pilot](../examples/price-comprehension/Focus-Price-Comprehension-Pilot.zip)

Start here. In a disposable copy of the Comparison sample, show a pair of workshop places. Give each visitor one randomly assigned version. One says “$350 for two people” and the other says “$350 per person.” Keep the layout, other offers and device the same. Before booking, ask “What is the total for two people using the pair offer?” The answer changes from $350 to $700. Verify the actual exported words and their fit before each session.

Record correct unaided answers out of everyone shown each version. Keep “unsure,” wrong answers and requests for help visible. If people miss the unit, change only where the offer puts that unit, then retest with fresh visitors. To compare Focus and a designer’s build, give both the same two variants and balance assignment across all four conditions. The CFPB used concrete comparison questions to assess redesigned disclosures and found that the improvement differed by question. The method transfers to this test. Its mortgage results supply no expected effect size for Focus. [CFPB assessment, section 3.3.2 and Table 3](https://files.consumerfinance.gov/f/documents/cfpb_trid-rule-assessment_report.pdf)

## 2. Can an owner safely pick up yesterday’s work?

Give a first-time owner a practice draft. Ask them to save a copy, try another layout without applying it, then leave for a short unrelated task. On return ask “Which version is saved? Show me where you would continue.” Compare the current experience with a prototype that shows the same short cue before leaving and after returning, for example “Saved copy · Journal.” Generate that cue from a confirmed save. Run a separate refused-save case and check that nobody is told the change succeeded.

Record the first design opened, seconds from return to the first correct action, help, and any edit to the wrong original. Count unfinished attempts alongside times for successful attempts. Altmann and Trafton found that pre-interruption visual cues helped people resume a simulated task. Whether such a cue helps a Focus owner is the experiment. [Task interruption and resumption cues](https://interruptions.net/literature/Altmann-CogSci04.pdf)

## 3. Does the intended character survive a developer handoff?

Use identical bookshop copy, images and layout for two briefs. One asks for a quiet reading room, the other a lively neighborhood events venue. Put only the visual intent in the brief. Have reviewers match an exported page to a brief with the theme and maker labels hidden. Repeat on a build made from the downloaded handoff by an independent coding assistant. Counterbalance order and collect “unclear” alongside matches. Compare the direct export and recipient build by brief. If the export communicates the brief but the rebuilt page loses it, inspect the handoff and returned fonts before changing the theme.

Use an independent designer’s build from the same inputs as a reference. Record brief fit separately from craft preference and visitor task success. Hazlett and colleagues found that changing typeface affected readers’ judgments of the emotional tone of onscreen pages. OpenAI’s evaluation guidance supports specific comparison questions, held-out examples and calibration against human reviewers. Keep a fresh brief pair for retesting. A successful pilot identifies a decision worth repeating across audiences and briefs. A claim of parity needs planned practical margins and enough independent evidence to estimate the differences.
