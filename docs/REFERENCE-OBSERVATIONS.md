# Audi and Firehouse as quality references

Captured November 18, 2026. These are reference observations, not a claim about how either site was authored or proof that Focus matches its quality.

| Reference | Directly observed | Transfer to Focus |
|---|---|---|
| [Audi](https://www.audi.com/en) | Restrained dark surfaces, wide custom typography, generous separation, category access, image-led model sections. | Showcase: a distinct image stage when supplied, purposeful typographic opening, clearly grouped links into detail. Keep selected Focus tokens and use owner imagery. |
| [Firehouse](https://www.firehouse.com/) | Centered masthead, lead story beside a compact supporting column, section labels and rules, repeated text/image hierarchy. | Journal: centered masthead, lead content with an index, scannable numbered sections. Use supplied copy without invented news, timestamps or categories. |

## Capture limits

The web connector verified current public navigation and page structure. The connected Browser control was unavailable and cloud CUA failed before opening a page. An isolated local Chromium session captured desktop and mobile layouts without sign-in. Audi's initial hero area was blank before media loaded; later image load flags confirmed available content. Full-page captures include unloaded sections because lazy content was not scrolled exhaustively. Consent overlays obscure part of both mobile captures. No claims about complete source interaction behavior or accessibility are made.

Source captures are retained in the development workspace at `artifacts/references/`; the release archive includes these observations rather than redistributing those source captures. Reference screenshots are evaluation material; no source logo, font, photography, article copy, tracking, or advertising is used in the authored templates. The new structures remain original and use the owner's own content. Their output is a static page, not a publication CMS or vehicle configurator.

## Evaluation distinction

A reference preference tells us what the owner admires. A fair human comparison requires a matched brief, assets and constraints, frozen outputs, and independent reviewers. Neither these screenshots nor an automated audit establishes indistinguishability.
