## Verification discipline

1. Name the smallest behavior and its user-visible result.
2. Reproduce the issue or establish the acceptance check.
3. Edit, run the narrow test, and resolve failures before expanding.
4. Stop source edits before the final validation run. If source changes during a run, retain that output as intermediate and rerun affected final checks against unchanged source.
5. Record what was actually tested, what remains untested, the source revision, and a recovery checkpoint.
