# Evidence at the return handoff

Research checked 18 November 2026 for the next Target slice. These are engineering sources and our implementation implications, not observed customer interviews or a claim of standards compliance.

- [SLSA 1.2 provenance](https://slsa.dev/spec/v1.2/provenance) distinguishes tracing source revisions from tracing build output to its source. **Focus implication:** comparing two returned source files establishes only their selected-byte identity. It does not establish a build or deployment. The first opened 1.1 page explicitly identified itself as retired; the current 1.2 page was consulted instead.
- [GitHub commit signature verification](https://docs.github.com/en/authentication/managing-commit-signature-verification/about-commit-signature-verification) describes verification of a change's signed origin. **Focus implication:** do not use a broad “Verified” badge for source equality or infer task correctness from a signature/hash. The current return check does not verify any signature or repository revision.
- [W3C WAI Easy Checks](https://www.w3.org/WAI/test-evaluate/preliminary/) explicitly limits a quick review and includes keyboard/focus, text resizing and form errors. Its [draft update](https://www.w3.org/WAI/test-evaluate/easy-checks/) retains that limited scope. **Focus implication:** actual visitor, visual, keyboard and narrow-screen checks remain necessary after a byte match; neither a matching patch nor a short checklist certifies accessibility.

The most useful next proof is therefore direct comparison of the actual two returned files with the current proposal. A JSON report copying expected hashes would be a recipient assertion, even if its format were valid. The Target task/preview/rollback answers also live in `TRIAL-PLAN.md`, outside `trial-contract.json`; a contract digest alone would not bind those answers. This slice deliberately adds no report importer or durable evidence record. The existing live proposal/context boundary remains the authority, and Launch remains separate.
